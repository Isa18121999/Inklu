# Prioridades de accesibilidad INKLU

Implementación prevista para la rama `feature/inklu-accessibility-priorities`.

1. Perfil + necesidades/preferencias de accesibilidad.
2. Información estructurada de accesibilidad de cada oferta.
3. Filtros de accesibilidad.
4. Empresa verificada.
5. Explicación de recomendaciones de IA.
6. Reporte de ofertas/discriminación.

La información de discapacidad y accesibilidad debe ser voluntaria, mínima y controlada por la persona usuaria. La compatibilidad no debe penalizar a una persona por declarar una discapacidad; se deben comparar requisitos del puesto, habilidades, preferencias y condiciones de accesibilidad.
