# INKLU — implementación de accesibilidad

Esta documentación acompaña la rama `feature/inklu-accessibility-priorities`.

## Alcance
- Preferencias y necesidades de accesibilidad del candidato.
- Criterios estructurados de accesibilidad por oferta.
- Filtros de accesibilidad.
- Verificación visible de empresas.
- Explicación de recomendaciones IA con factores de accesibilidad.
- Reportes de ofertas y posibles casos de discriminación.

## Principios
- La declaración de discapacidad es voluntaria.
- No se penaliza el matching por declarar discapacidad.
- Se recomienda comparar habilidades, requisitos, preferencias y condiciones del puesto.
- La oferta debe diferenciar información declarada de información no proporcionada.
