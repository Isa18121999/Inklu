# INKLU

Prototipo web de INKLU basado en el diseño UX/UI de la aplicación móvil de inclusión laboral.

## Diseño implementado
- Pantalla de inicio con logo, **Empezar** e **Iniciar sesión**.
- Selección de rol: candidato o empresa.
- Registro de candidato con campo de CONADIS.
- Registro de empresa sin sección de accesibilidad.
- Dashboards, ofertas y postulaciones.
